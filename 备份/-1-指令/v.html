Vue 常用 v- 指令汇总与示例（Vue 3）

页面使用 Vue 3 CDN，直接打开此文件可交互练习。

v-cloak

避免闪烁，Vue 未挂载前隐藏元素，挂载后自动移除属性。

页面已渲染：{{ readyMessage }}
示例：<div id="app" v-cloak> ... </div>

v-text 与 v-html

v-text 等价于把文本设置为元素的 textContent；v-html 会把字符串作为 HTML 插入（需注意 XSS）。

// v-text: 安全地显示文本
// v-html: 将字符串解析为 HTML（慎用）
<p v-text="textExample"></p>
<p v-html="htmlExample"></p>

v-bind（缩写为 :）

用于绑定属性；支持动态参数 v-bind:[attrName]。

动态属性：

我是动态属性目标元素
// 例：<img :src="imgSrc">  或  <div v-bind:[dynamicAttrName]="dynamicAttrValue">

v-on（缩写为 @）及修饰符

监听事件并处理；常见修饰符：.stop、.prevent、.once、.self、.passive

提交表单（.prevent）
// 例如：<button @click.stop="fn"> 阻止冒泡
// <form @submit.prevent="onSubmit"> 阻止默认提交
// <button @click.once="handler"> 只触发一次

v-model 与修饰符（.lazy .trim .number）

双向绑定输入。修饰符：.lazy（change 触发）、.trim（去除首尾空格）、.number（转成数字）。

绑定结果：{{ name }}

lazy: {{ lazyInput }} | trim: '{{ trimInput }}' | number: {{ numInput }} (type: {{ typeof numInput }})

// 示例： <input v-model.trim="text" /> <input v-model.number="n" />

v-if / v-else-if / v-else 与 v-show

v-if 控制是否渲染节点（销毁/重建）；v-show 仅切换 CSS 的 display。

v-for 列表渲染（注意必须添加 key）

v-for 支持数组、对象、基于 index 的遍历，建议为每一项提供唯一 key。

  • {{ idx }} - {{ item.text }}
// 示例： <li v-for="(item, idx) in items" :key="item.id"> ... </li>

v-pre 与 v-once

v-pre 跳过该元素及子元素的编译（显示原始模板）；v-once 只渲染一次，之后不会更新。

{{ 2 + 2 }}（显示原始模板，不会计算）

{{ onceText }}

动态组件（v-is / :is）

通过 :is 动态切换组件或标签。

插槽（v-slot / #）

父组件向子组件传递内容，使用具名插槽或默认插槽。

v-bind:class 与 v-bind:style

可以绑定对象、数组或计算属性来动态设置 class/style。
